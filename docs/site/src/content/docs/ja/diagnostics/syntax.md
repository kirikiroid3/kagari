---
title: "構文 (E0xxx)"
---

構文エラーは、名前解決や型検査よりも前にパーサーが報告します。構文エラーのあるファイルもできるかぎり解析を続けるため、ほかの診断が続けて出ることがあります。ただし、多くは構文エラーを直せば消えます。

## E0001 `syntax` {#e0001}

**エラー。** ソースが Kagari として解析できないか、そのファイル種別では使えない構文が含まれています。たとえば `.kis` ファイルに書けるのは素のスクリプトコードだけなので、`s!`、`choice!`、`t!` などの物語用の組み込み構文は使えません。

```kis
#[scene]
pushdown fn Scene() {
    s!(t!["x"]);
}
```

直し方：指摘された構文を直すか、組み込み構文を使うコードを `.kix` ファイルに移します（この例では `main.kis` を `main.kix` に改名します）。
