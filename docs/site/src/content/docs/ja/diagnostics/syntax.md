---
title: "構文 (E0xxx)"
---

構文エラーは、名前解決や型検査より前にパーサーが報告します。構文エラーのあるファイルも可能な限り解析を続けるため、後続の診断が出ることもありますが、まず構文エラーを直すと多くの場合それらも消えます。

## E0001 `syntax` {#e0001}

**エラー。** ソーステキストが Kagari として解析できないか、そのファイル種別では許されない構文を使っています。たとえば `.kis` ファイルは素のスクリプトコードしか受け付けないため、`s!`、`choice!`、`t!` などの物語フォームは書けません。

```kis
#[scene]
pushdown fn Scene() {
    s!(t!["x"]);
}
```

修正方法: 報告された構文を直すか、フォームを使うコードを `.kix` ファイルに移します（この例では `main.kis` を `main.kix` に改名します）。
