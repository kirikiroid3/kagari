---
title: "診断"
---

Kagari コンパイラが出す診断には、すべて番号付きのコードが付いています。この部では、コードごとに意味、そのコードが出る最小のプログラム、直し方を説明します。

## コード {#codes}

コードは英字 1 文字と数字 4 桁でできています（例：`E2001`）。

- `E` はエラー、`W` は警告を表します。警告は、同じ検査のエラーと同じ番号帯を使います。そのため `W2039` は型エラーの番号帯に入っています。
- 先頭の数字は、どの検査が報告したかを表します。

| コード | 検査 | ページ |
| ----- | ----- | ---- |
| `E0xxx` | 構文 | [構文](syntax.md) |
| `E1xxx` | モジュール、アイテム、名前解決、アセット | [モジュール、アイテム、名前](modules.md) |
| `E2xxx`, `W2xxx` | 型、パターン、`match` の網羅性 | [型](types.md) |
| `E3xxx`, `W3xxx` | 種別（`fn`、`pushdown fn`、`const fn`、シーンの規則） | [種別](kinds.md) |
| `E4xxx` | 定数評価 | [定数評価](eval.md) |
| `E5xxx`, `W5xxx` | 物語の解析 | [物語の解析](analysis.md) |
| `E6xxx`, `W6xxx` | ゲームシステムの検査 | [ゲームシステム](system.md) |
| `E7xxx` | バイトコード生成 | [出力](emit.md) |

## 重大度 {#severity}

- **エラー**があるとビルドは止まります。エラーが一つでも残っていれば、`kagari build` は `.kagari` ファイルを書き出さず、`kagari check` は 0 以外の終了ステータスで終わります。
- **警告**は、誤りの可能性が高い箇所を知らせます（到達しない `match` アーム、`#[must_use]` の値の破棄、到達しないシーンなど）。ビルド自体は成功します。

## 出力形式 {#output-format}

`kagari check` と `kagari build` は、診断を 1 件につき 1 行で表示します。

```text
path:line:col: error[E2001]: message
```

警告なら `warning[W2039]` の形になります。行と列は 1 から数え、列はバイト数ではなく文字数です。パスはプロジェクトディレクトリからの相対パスです。診断が別の箇所にも関係する場合は、その後に字下げした注記行が続きます。

```text
src/main.kis:2:4: error[E1014]: message
  note: src/main.kis:1:4: message
```

報告する診断がなければ、`kagari check` は `no diagnostics` と表示します。言語サーバーも、同じコードとメッセージの診断をエディタ上に表示します。

## コードの調べ方 {#looking-a-code-up}

各コードには、小文字のコードをアンカーにした見出しがあります。たとえば `E2001` なら [`types.md#e2001`](types.md#e2001) を開きます。ページはコードの先頭の数字で決まり（上の表を参照）、アンカーは `#` の後に小文字のコードを続けた形（例：`#w5009`）です。
