---
title: "Rust との違い"
---

Kagari の構文は、Rust のサブセットにいくつかの機能を足したものです。このリファレンスで特に断りがない限り、構文の意味は Rust と同じです。この章では、Rust に慣れた人が注意すべき違いをまとめます。Rust にあって Kagari にないもの、その代わりに使うもの、見慣れた構文なのに動きが違うものを取り上げます。

## 言語にないもの {#what-is-not-in-the-language}

| Rust の機能 | ない理由、または代わりのもの |
| ----------- | ---------------------------- |
| ライフタイム、借用チェッカー、ムーブ、`Drop` | 値はコピーされ、参照は共有ポインタです。[値、参照、クロージャ](./values.md)を参照 |
| 浮動小数点数（`f32`、`f64`） | 浮動小数点数は `Eq` を実装できず、プラットフォームによって結果も変わります。一方、画面は厳密に比較できなければなりません。代わりに `Decimal`（`0.5`）か `Rat` を使います。[数値](./numbers.md)を参照 |
| `as` キャスト | `x.into()`（情報を失わない検査付きの変換）と `x.saturate()`（範囲内に丸める変換）を使います。`as` は構文としては読めますが、エラー `E2019` になります |
| ユーザー定義のトレイト、`impl Trait for T`、`derive` | トレイトは標準ライブラリの `#[builtin]` トレイトしかありません（`E1012`、`E1023`）。`Eq` は自動で実装されます。[言語トレイト](../special/traits.md)を参照 |
| `dyn Trait`、`impl Trait` 型、`where` 句、`<T as Trait>::f` | 標準のトレイトしかないため不要です。境界はジェネリクスの型引数の並びに書きます（`T: Eq`） |
| マクロ（`macro_rules!`、`println!`、`vec!` など） | テンプレートやインクルードでしていたことは、関数とシーンで書けます。[組み込み構文](./forms.md)は構文に組み込まれた固定のものです |
| `unsafe`、生ポインタ、`extern` | 不要です。コードは検証済みの VM で動きます |
| `async`、スレッド | ステップで物語を中断する仕組みが言語に組み込まれています。[ステップ](../concepts/steps.md)を参照 |
| `goto`、位置としてのラベル | 構造化された制御フローしかありません。[制御フローとループ](./control-flow.md#no-goto)を参照 |
| `char`、バイト文字列、生文字列、`&str` | 文字列リテラルの型は `Text` です。実行時の文字列には `String` を使います |
| `Box`、`Rc`、`HashMap`、スライス | 配列 `[T; N]` と `Vec<T>` を使います。型はすべて値型です |
| `Iterator` トレイト、`.iter()`、`.map(…)` の連鎖 | `for` ループで配列、`Vec<T>`、整数の範囲を直接回します |
| `move` クロージャ | クロージャは常に値でキャプチャします |
| `let … else`、`if let … && …` の連鎖、ラベル付きブロック | `match`、入れ子の `if let`、ループのラベルを使います |
| スライスパターン、`&` パターン、`ref`、`name @ pattern` | 使えるパターンは[パターン](./patterns.md#pattern-forms)を参照 |
| 構造体更新構文 `S { a: 1, ..base }` | フィールドをすべて書きます |
| `#[derive]`、`#[cfg]`、`#[test]` などの属性 | 使えるのは `#[scene]`、`#[entry]`、`#[must_use]`、`#[shader_arg]`（と標準ライブラリ内の `#[builtin]`）だけです。それ以外の属性はエラー `E1006` になります。[属性](../special/attributes.md)を参照 |
| `pub(crate)`、`pub(super)` | `pub` しかありません |
| 値としての開いた範囲 `a..`、`..b`、`..=b`、`..` | 範囲式には両端が必要です（`E2030`）。パターンでは `a..` と `..=b` は書けますが、`..b` は書けません。[範囲パターン](./patterns.md#range-patterns)を参照 |

## 動きが違うもの {#things-that-work-differently}

### 関数種別 {#function-kinds}

関数にはすべて種別があります。`fn`、`pushdown fn`、`const fn` のいずれかで、`pushdown fn` には `#[scene]` も付けられます。何を呼べて何ができるかは種別で決まります。`const fn` は純粋で、物語変数、設定、メタデータを読めません。[関数種別](../concepts/kinds.md)を参照してください。

### 数値 {#numbers}

- `Int<lo, hi>` は範囲付き整数のプリミティブ型です。演算では結果の範囲が計算され、複合代入はオーバーフローせず上下限で飽和します。
- 整数型どうしが暗黙に変換されることはありません。例外は整数リテラルと、ある `Int` 型からその範囲を含む別の `Int` 型への拡大だけです。
- 型の決まらない整数リテラルは Rust と同じく `i32` になります。ただし `i32` は有限型ではないので、物語のコードではカウンタの型を明記します。`let mut i = 0;` ではなく `let mut i: Int<0, 9> = 0;` と書きます。
- オーバーフローとゼロ除算は、定数のコードではコンパイルエラー、実行時にはパニックになります。ラップアラウンドする演算はありません。
- `Int<lo, hi>` に対する `match` は、`lo` から `hi` までを網羅していれば `_` なしでも網羅的とみなされます。

[数値](./numbers.md)を参照してください。

### 値と参照 {#values-and-references}

代入、引数渡し、戻り値では、どれも値がコピーされます。`&T` と `&mut T` は借用チェッカーのない共有ポインタで、`fn` と `const fn` のコードでは同じ場所を指す `&mut` が 2 つ同時にあってもかまいません。`pushdown fn` の中では参照とクロージャは第二級で、渡して呼び出すことはできても、格納したり返したりはできません。[値、参照、クロージャ](./values.md)を参照してください。

### 等価性と順序 {#equality-and-ordering}

`PartialEq` と `PartialOrd` はありません。`==` と `!=` は標準トレイト `Eq` を使います。構造的に比較できる型はすべて `Eq` を自動で実装しますが、クロージャは実装しません（`E2017`）。`<`、`>`、`<=`、`>=` が使えるのは整数、`Int`、`Decimal`、`Rat` だけです（`E2015`）。

### static {#statics}

`static mut` は[物語変数](../concepts/story.md#story-variables)の宣言です。安全に使えますが、使えるのは `pushdown fn` のコードからだけです（`E3007`）。不変の `static` に入れられるのは `Setting` か `Meta` のハンドルに限られます（`E3011`）。それ以外の定数には `const` を使います。

### 束縛とパターン {#bindings-and-patterns}

- 束縛への代入は、たとえ最初の代入でも変更とみなされます。初期化子のない `let` にあとから代入するなら、`let mut` にしなければなりません（`E3017`）。
- 構造体パターンでは、`..` を書かなくてもフィールドを省略できます。
- `..b` はパターンとしては書けません。書けるのは `..=b` だけです。

### `?` 演算子 {#the-try-operator}

`?` は Rust と同じく `Option` と `Result` に使えますが、エラーを `From` で変換する仕組みはありません。関数は同じエラー型の `Result` を返す必要があります（`E2034`）。

### 文字列とテキスト {#strings-and-text}

文字列リテラルの型は `&str` ではなく `Text` で、ゲームに表示する定数のテキストを表します。`.kix` ファイルでは、リッチテキストを [`t![…]`](./forms.md#t) で書きます。`String` は、`fn` のコードが実行時に組み立てるテキストの型です。

### ファイル {#files}

`.kis` ファイルには素のコードを書きます。`.kix` ファイルではさらに[組み込み構文](./forms.md)も使えます。[ソースファイルとモジュール](./modules.md)を参照してください。
